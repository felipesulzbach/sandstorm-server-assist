Бесплатное приложение для Windows, которое помогает **установить, настроить и запустить выделенный сервер
Insurgency: Sandstorm с модами mod.io** без ручной правки файлов `.bat` и `.ini`.

> Неофициальный инструмент сообщества. Не связан с New World Interactive, Focus Entertainment, Valve или mod.io.
> См. [DISCLAIMER.md](DISCLAIMER.md).

## Скачать

Скачайте последнюю версию на **[странице релизов (Releases)](https://github.com/felipesulzbach/sandstorm-server-assist/releases/latest)**:

- **Установщик** (`…-windows-setup.exe`, рекомендуется): устанавливается для вашего пользователя Windows без прав
  администратора и обновляется сам.
- **Портативная версия** (`…-windows-portable.zip`): распакуйте и запустите; она только сообщает о новой версии.

Нужна Windows 10 или 11. Windows может показать предупреждение SmartScreen, потому что у приложения нет цифровой
подписи: нажмите **Подробнее** › **Выполнить в любом случае**. В каждом релизе указан SHA-256 файлов.

## Возможности

- **Пошаговая настройка:** список на Панели показывает, что готово и чего не хватает.
- **Установка с прогрессом:** скачивает SteamCMD (подпись Valve проверяется) и устанавливает или обновляет сервер,
  показывая скорость и оставшееся время.
- **Используйте уже готовый сервер:** выберите его папку, и приложение прочитает настройки, спрашивая перед тем, как
  изменить введённое вами.
- **Все настройки в одном месте:** название, порты, игроки, карты и ротация, карты из модов, день или ночь, мутаторы
  (в том числе из ваших модов), 60 правил игры, администраторы, пароли и токены, с подсказками «Как получить?».
- **Моды mod.io:** авторизуйте сервер один раз, следите за загрузкой каждого мода; приложение один раз перезапустит
  сервер, когда это нужно новым модам.
- **Запуск:** старт и остановка с этапами в реальном времени, смена карты на работающем сервере, панель игроков
  (кик, бан, сообщение), сообщение дня и сообщения о входе и выходе.
- **Автоматизация:** сообщения по расписанию, ежедневный перезапуск с предупреждением и обновлением, перезапуск после
  сбоя, уведомления в Discord, запуск вместе с Windows.
- **Диагностика портов:** проверяет брандмауэр, роутер (UPnP), ваш публичный IP, CGNAT и Steam и объясняет, как
  проверить с другом.
- **Понятные ошибки и чистые журналы:** каждая известная ошибка говорит, что случилось, почему и как исправить; пароли
  и токены всегда скрыты.
- **Защищённые секреты и переносимая резервная копия:** Windows шифрует секреты (DPAPI); один файл с паролем переносит
  всё на другой ПК.
- **Обратная связь:** сообщите о проблеме или предложите идею прямо из приложения, с журналом и снимком экрана по
  желанию.
- **5 языков и 5 тем:** English, Português, Español, Русский, Українська.

## Быстрый старт

1. Установите приложение и примите условия использования.
2. **Установка:** выберите папку сервера (около 25 ГБ свободно), скачайте SteamCMD и установите сервер. Если сервер
   уже есть, выберите его папку.
3. **Сервер:** задайте название, карты и пароли. Получите токен игрового сервера Steam (GSLT) по подсказке.
4. **Моды:** авторизуйте сервер в mod.io и подпишитесь на моды на сайте mod.io.
5. **Сервер › Сеть:** пробросьте игровой порт и порт запросов (UDP) в роутере, создайте правило брандмауэра и
   нажмите **Диагностика портов**.
6. **Панель:** нажмите **Запустить сервер** и отправьте игрокам команду для входа.

Полное руководство с картинками — в **[руководстве пользователя](docs/ru/GUIDE.md)**.

## Сборка из исходников

Требования: Windows 10/11 (WebView2), Go 1.27, Node.js 24; NSIS для установщика.

```bash
npm install
npm run dev               # приложение в режиме разработки
npm test                  # тесты Go, интерфейса и документации
npm run build             # desktop/build/bin/sandstorm-server-assist.exe
npm run build:installer   # установщик в desktop/build/dist
```

Wails 2 (Go, Clean/Hexagonal) + React 19 + Vite. Правила находятся в Go (`desktop/internal`); экраны отправляют только
идентификаторы и параметры. Техническая документация на английском: [архитектура](docs/ARCHITECTURE.md),
[решения](docs/DECISIONS.md), [выпуск версий](docs/RELEASING.md) и [как помочь проекту](CONTRIBUTING.md).
