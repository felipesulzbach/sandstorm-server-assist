How to install

  1. Download and open sandstorm-server-assist-setup.exe.
  2. Windows may say the app is not recognized (SmartScreen). Click More info and then Run anyway.
  3. Follow the installer (no administrator needed) and open Sandstorm Server Assist from the Start menu.
  4. Accept the terms of use and the privacy notice, then follow the first steps on the dashboard.

Prefer not to install? Download the portable version, extract it and open sandstorm-server-assist.exe. It does not update itself: come back here for new versions.

Check the download

To be sure the file arrived complete, compare the SHA-256 (in PowerShell: Get-FileHash file).
