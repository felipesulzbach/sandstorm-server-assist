Безкоштовний застосунок для Windows, який допомагає **встановити, налаштувати й запустити виділений сервер
Insurgency: Sandstorm з модами mod.io** без ручного редагування файлів `.bat` і `.ini`.

> Неофіційний інструмент спільноти. Не пов'язаний з New World Interactive, Focus Entertainment, Valve чи mod.io.
> Див. [DISCLAIMER.md](DISCLAIMER.md).

## Завантаження

Завантажте останню версію на **[сторінці релізів (Releases)](https://github.com/felipesulzbach/sandstorm-server-assist/releases/latest)**:

- **Інсталятор** (`…-windows-setup.exe`, рекомендовано): встановлюється для вашого користувача Windows без прав
  адміністратора й оновлюється сам.
- **Портативна версія** (`…-windows-portable.zip`): розпакуйте й запустіть; вона лише повідомляє про нову версію.

Потрібна Windows 10 або 11. Windows може показати попередження SmartScreen, бо застосунок не має цифрового підпису:
натисніть **Докладніше** › **Однаково запустити**. У кожному релізі вказано SHA-256 файлів.

## Можливості

- **Покрокове налаштування:** список на Панелі показує, що готово, а чого бракує.
- **Встановлення з прогресом:** завантажує SteamCMD (підпис Valve перевіряється) і встановлює або оновлює сервер,
  показуючи швидкість і час, що залишився.
- **Використайте наявний сервер:** виберіть його теку, і застосунок прочитає налаштування, запитуючи перед тим, як
  змінити введене вами.
- **Усі налаштування в одному місці:** назва, порти, гравці, мапи й ротація, мапи з модів, день чи ніч, мутатори
  (зокрема з ваших модів), 60 правил гри, адміністратори, паролі й токени, з підказками «Як отримати?».
- **Моди mod.io:** авторизуйте сервер один раз, стежте за завантаженням кожного мода; застосунок один раз перезапустить
  сервер, коли цього потребують нові моди.
- **Запуск:** старт і зупинка з етапами в реальному часі, зміна мапи на працюючому сервері, панель гравців (кік, бан,
  повідомлення), повідомлення дня та повідомлення про вхід і вихід.
- **Автоматизація:** повідомлення за розкладом, щоденний перезапуск із попередженням і оновленням, перезапуск після
  збою, сповіщення в Discord, запуск разом із Windows.
- **Діагностика портів:** перевіряє брандмауер, роутер (UPnP), ваш публічний IP, CGNAT і Steam та пояснює, як
  перевірити з другом.
- **Зрозумілі помилки й чисті журнали:** кожна відома помилка каже, що сталося, чому і як виправити; паролі й токени
  завжди приховані.
- **Захищені секрети й переносна резервна копія:** Windows шифрує секрети (DPAPI); один файл із паролем переносить усе
  на інший ПК.
- **Зворотний зв'язок:** повідомте про проблему або запропонуйте ідею просто із застосунку, з журналом і знімком
  екрана за бажанням.
- **5 мов і 5 тем:** English, Português, Español, Русский, Українська.

## Швидкий старт

1. Встановіть застосунок і прийміть умови використання.
2. **Встановлення:** виберіть теку сервера (близько 25 ГБ вільного місця), завантажте SteamCMD і встановіть сервер.
   Якщо сервер уже є, виберіть його теку.
3. **Сервер:** задайте назву, мапи й паролі. Отримайте токен ігрового сервера Steam (GSLT) за підказкою.
4. **Моди:** авторизуйте сервер у mod.io і підпишіться на моди на сайті mod.io.
5. **Сервер › Мережа:** перенаправте ігровий порт і порт запитів (UDP) у роутері, створіть правило брандмауера й
   натисніть **Діагностика портів**.
6. **Панель:** натисніть **Запустити сервер** і надішліть гравцям команду для входу.

Повний посібник із малюнками — у **[посібнику користувача](docs/uk/GUIDE.md)**.

## Збирання з вихідного коду

Вимоги: Windows 10/11 (WebView2), Go 1.27, Node.js 24; NSIS для інсталятора.

```bash
npm install
npm run dev               # застосунок у режимі розробки
npm test                  # тести Go, інтерфейсу та документації
npm run build             # desktop/build/bin/sandstorm-server-assist.exe
npm run build:installer   # інсталятор у desktop/build/dist
```

Wails 2 (Go, Clean/Hexagonal) + React 19 + Vite. Правила містяться в Go (`desktop/internal`); екрани надсилають лише
ідентифікатори й параметри. Технічна документація англійською: [архітектура](docs/ARCHITECTURE.md),
[рішення](docs/DECISIONS.md), [випуск версій](docs/RELEASING.md) і [як допомогти проєкту](CONTRIBUTING.md).
